PARTE 2: PLANTILLAS MAESTRAS, MENÚ DESPLEGABLE Y ESTRUCTURA VISUAL
Objetivo de esta parte: Crear los archivos layout (plantillas) que usarán todas las páginas, e implementar el sistema de navegación (Header con menú desplegable y Footer) que sea funcional tanto en móviles como en escritorio.

Pasos pequeños para la IA:

Crear la plantilla base global (_layouts/default.html):

Este archivo será el "molde" maestro de todo el sitio.

Debe contener la estructura básica de un documento HTML5 (declaración DOCTYPE, etiquetas <html> en español, <head> y <body>).

Dentro del <head>, se debe incluir:

La codificación UTF-8.

La ventana gráfica (viewport) para que sea responsive.

El título dinámico ({{ page.title }} si existe, o el título general del sitio).

La llamada a la hoja de estilos principal (assets/css/style.css - aunque sea .scss, Jekyll lo procesa).

La llamada a las fuentes de Google (Playfair Display e Inter) desde el CDN.

Dentro del <body>, el contenido debe estar organizado en tres grandes bloques:

Bloque 1: {% include header.html %} (aquí se inyectará el menú).

Bloque 2: <main class="contenido-principal">{{ content }}</main> (aquí se inyectará el contenido único de cada página).

Bloque 3: {% include footer.html %} (aquí se inyectará el pie de página).

Añadir un enlace al archivo JavaScript principal (assets/js/main.js) justo antes de cerrar el </body> para mejorar la velocidad de carga.

Diseñar la lógica del menú desplegable en el Header (_includes/header.html):

El header debe contener dos partes claras: el logo (o nombre "🌺 Jamaica") a la izquierda, y la navegación a la derecha.

Para escritorio (pantallas grandes): La navegación debe mostrar los enlaces "Inicio" y un botón/enlace llamado "Explorar" que, al pasar el ratón por encima (hover), despliegue un recuadro con los 4 enlaces a las subpáginas: Apariencia, Composición, Beneficios, Usos.

Para móviles (pantallas pequeñas): El menú completo debe ocultarse detrás de un botón de "hamburguesa" (☰). Al hacer clic en este botón, se debe mostrar el menú en vertical. Dentro de este menú móvil, el elemento "Explorar" debe funcionar como un acordeón: al tocarlo, se despliegan o esconden los 4 enlaces de las subpáginas sin recargar la página.

Requisito técnico (sin código): Instruir a la IA para que implemente esta funcionalidad usando únicamente el truco del input checkbox (para el menú hamburguesa) y el hover combinado con focus-within (para el desplegable en escritorio). Esto asegura que funcione sin JavaScript pesado, aunque el main.js lo usaremos para añadir el efecto de cierre al hacer clic fuera del menú.

Construir el Pie de Página (_includes/footer.html):

Crear un footer elegante y minimalista, dividido en dos filas:

Fila superior: Un espacio para incluir 3 o 4 iconos de redes sociales (usando íconos SVG inline para no depender de librerías pesadas, o en su defecto, FontAwesome vía CDN). Colocar textos como "Síguenos" o "Contacto".

Fila inferior: Un texto de copyright que incluya el año actual y el nombre del sitio. Ejemplo: "© 2026 Flor de Jamaica. Diseñado con esencia natural."

Asegurarse de que el footer tenga un color de fondo ligeramente distinto (por ejemplo, el verde oscuro #3D6B4F con texto blanco) para cerrar visualmente la página, o mantenerlo en blanco roto con una línea decorativa en rojo profundo.

Crear la plantilla para las subpáginas (_layouts/page.html):

Esta plantilla debe "heredar" la estructura de default.html (usando layout: default en el Front Matter dentro del propio archivo).

Su función específica es dar formato al contenido de las 4 subpáginas (Apariencia, Composición, Beneficios, Usos).

Debe incluir un encabezado de página (Hero interno): un título grande con el nombre de la sección, un pequeño subtítulo decorativo y una línea delgada del color rojo Jamaica (#B71F3E) debajo.

El cuerpo del contenido debe mostrarse en un contenedor centrado, con un ancho máximo de 800px (para que los textos largos sean fáciles de leer) y un fondo blanco o ligeramente crema.

Esta plantilla debe procesar correctamente el texto en Markdown (por ejemplo, las listas de minerales y los títulos ## del archivo .txt que subiste).

Enlazar las rutas del menú con la estructura de archivos:

Verificar que los enlaces del menú desplegable apunten a las URLs que tendrán las futuras subpáginas:

Inicio → / (raíz).

Apariencia → /apariencia/

Composición → /composicion/

Beneficios → /beneficios/

Usos → /usos/

(Aunque estas páginas aún no existen, la IA debe dejar las rutas escritas correctamente para la Parte 3).
