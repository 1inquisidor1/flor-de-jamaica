PARTE 4: INTERACTIVIDAD, COMPORTAMIENTO DINÁMICO Y OPTIMIZACIÓN
Objetivo de esta parte: Programar el comportamiento dinámico del sitio (slider con fundido, menú táctil, efectos de aparición al hacer scroll, y header inteligente). Además, prepararemos el sitio para que sea compartible en redes sociales con las metaetiquetas adecuadas.

Pasos pequeños para la IA (sin código explícito, solo lógica funcional):

1. Escribir el archivo JavaScript principal (assets/js/main.js):

Este archivo debe gestionar tres misiones claras, cada una en su propio bloque o función, sin interferir entre ellas:

Misión A: Control del Slider (Carrusel).

Misión B: Control del Menú Móvil (Hamburguesa y Acordeón).

Misión C: Efectos de Scroll y Header inteligente.

2. Lógica del Slider (Carrusel con efecto Fade):

Objetivo: Las 3 diapositivas del inicio deben cambiar automáticamente cada 4 segundos con un efecto de fundido suave (opacidad 0 a 1).

Instrucción a la IA:

Al cargar la página, el script debe buscar el contenedor del slider y guardar una lista de todas las diapositivas.

Debe mostrar solo la primera diapositiva (activa) y ocultar las demás.

Crear un temporizador (intervalo) que, cada 4 segundos, elimine la clase "activa" de la diapositiva actual, la oculte (opacidad 0), y se la añada a la siguiente (opacidad 1).

Comportamiento inteligente (Pausa): Si el usuario pasa el ratón por encima del slider (o lo toca en móvil), el temporizador debe detenerse. Cuando el usuario retire el ratón/dedo, el temporizador debe reiniciarse desde cero. Esto evita que el carrusel cambie mientras el usuario está leyendo un texto superpuesto.

Controles extras (Dots o Flechas): Crear pequeños círculos indicadores (uno por cada diapositiva) en la parte inferior del slider. Al hacer clic en un círculo, el slider debe saltar directamente a esa diapositiva y reiniciar el temporizador.

3. Lógica del Menú Móvil (Hamburguesa y Acordeón para "Explorar"):

Objetivo: Que el menú de navegación se comporte como una app nativa en móviles.

Instrucción a la IA:

Apertura y Cierre: El script debe detectar el clic en el botón de la hamburguesa (☰). Al hacer clic, debe añadir o quitar una clase (ej: menu-abierto) al contenedor del menú para mostrarlo u ocultarlo con una transición suave de despliegue.

Cierre automático al navegar: Cuando el usuario haga clic en cualquier enlace del menú (Inicio o cualquiera de las subpáginas), el script debe cerrar automáticamente el menú móvil para que no tape el contenido al cargar la nueva página.

Cierre al hacer clic fuera: Si el usuario hace clic en el fondo (en el área principal de la página) mientras el menú está abierto, el script debe detectarlo y cerrar el menú.

Lógica del acordeón "Explorar": Dentro del menú móvil, el elemento "Explorar" debe funcionar como un acordeón. Al hacer clic en él, el submenú (las 4 subpáginas) debe desplegarse u ocultarse sin recargar la página. Solo debe estar desplegado si el usuario lo toca, y al tocar otro enlace o fuera, debe cerrarse.

4. Efectos de Scroll elegantes (Revelado de elementos):

Objetivo: Que los elementos aparezcan con un sutil movimiento al hacer scroll hacia abajo (dar sensación de fluidez y cuidado).

Instrucción a la IA:

Utilizar la API nativa de Intersection Observer (no usar librerías externas para esto, es muy ligera).

Configurar un observador que vigile todos los elementos que tengan una clase especial (ej: animar-entrada).

Regla de aparición: Cuando un elemento con esa clase entre en el viewport (la pantalla visible), el script debe añadirle una segunda clase (ej: visible) que active una animación CSS predefinida.

Efecto visual (CSS): La animación debe ser muy sutil: el elemento comienza con opacity: 0 y transform: translateY(30px) y, al volverse visible, pasa a opacity: 1 y translateY(0) en 0.6 segundos.

Aplicación: Aplicar esta clase animar-entrada a las tarjetas de la página de inicio y a los bloques de subtítulos (<h2>) y párrafos largos de las subpáginas. Esto hará que la lectura sea más dinámica.

5. Comportamiento del Header (Efecto Glassmorphism al bajar):

Objetivo: Que la barra de navegación se vuelva "borrosa" y elegante al hacer scroll para no perder el contexto visual.

Instrucción a la IA:

El script debe detectar la posición del scroll vertical (window.scrollY).

Regla de transición: Cuando el usuario baje más de 80 píxeles desde la parte superior de la página, el script debe añadir una clase (ej: header-scrolled) al elemento <header>.

Efecto visual (CSS): Esa clase debe activar un fondo con backdrop-filter: blur(12px) y una ligera sombra. Esto hará que el contenido de la web se vea a través del header de forma transparente, dándole un toque moderno y "premium". Cuando el usuario vuelva al tope de la página, la clase se elimina y el header recupera su fondo sólido o transparente.

6. Preparación para Redes Sociales (SEO y Open Graph):

Objetivo: Que al compartir el enlace de la web en WhatsApp, Facebook o X (Twitter), aparezca una imagen bonita, un título y una descripción.

Instrucción a la IA (para que modifique el <head> en _layouts/default.html):

Añadir las etiquetas meta básicas de Open Graph:

<meta property="og:title" content="Flor de Jamaica - Elegancia Natural">

<meta property="og:description" content="Descubre la belleza, propiedades y usos de esta flor excepcional.">

<meta property="og:image" content="URL-de-la-imagen-que-subiremos"> (Dejar la ruta fija a assets/images/slider/foto1.jpg para que el usuario solo tenga que reemplazar esa imagen por una bonita).

<meta property="og:url" content="URL-del-sitio"> (Usar la variable {{ site.url }} si está configurada, o dejarlo genérico).

Añadir la metaetiqueta para Twitter Cards (twitter:card).

7. Optimización de carga (Estrategia "Defer"):

Instrucción a la IA: Asegurar que el enlace al archivo main.js dentro del default.html incluya el atributo defer. Esto garantiza que el JavaScript se descargue mientras el navegador pinta el HTML, pero se ejecute solo después de que la estructura de la página esté completamente cargada, evitando que el usuario vea un "bloqueo" o contenido saltando.
