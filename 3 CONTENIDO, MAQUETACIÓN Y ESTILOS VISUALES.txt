PARTE 3: CONTENIDO, MAQUETACIÓN Y ESTILOS VISUALES
Objetivo de esta parte: Crear los 5 archivos de contenido (1 inicio + 4 subpáginas) utilizando el texto del archivo flor de Jamaica.txt, y definir las reglas de estilo (CSS/SCSS) que transformarán esa estructura en un diseño limpio, elegante y completamente adaptativo.

Pasos pequeños para la IA:

1. Crear la página de Inicio (index.md):

Front Matter (cabecera): Debe declarar layout: home y un title: "Inicio" (aunque no se muestre como título principal, servirá para el SEO).

Estructura del contenido (en Markdown y HTML básico):

Sección 1 (Hero/Slider): Insertar un contenedor especial donde se mostrará el carrusel de imágenes (las 3 fotos impactantes de la flor). Por ahora, se colocan 3 elementos div o figure con textos superpuestos cortos como: "La flor que cautiva", "Naturaleza en cada pétalo", "Tradición y salud". (Las rutas de las imágenes se dejarán como assets/images/slider/foto1.jpg, foto2.jpg, foto3.jpg; el usuario las agregará después).

Sección 2 (Mensaje de bienvenida): Un párrafo breve y poético que invite a explorar. Debe sintetizar la esencia del texto: "La flor de Jamaica no solo es un espectáculo visual; su cáliz rojo encierra siglos de tradición, una riqueza nutricional excepcional y múltiples beneficios para tu bienestar. Acompáñanos a descubrirla."

Sección 3 (Tarjetas de acceso rápido): Un grid de 4 tarjetas. Cada tarjeta debe mostrar:

Un pequeño ícono o emoji representativo (ej: 🌿 para Apariencia, 🧪 para Composición, ❤️ para Beneficios, 🍹 para Usos).

El título de la subpágina (Apariencia, Composición, Beneficios, Usos).

Una frase muy corta extraída del texto (ej: para Apariencia: "De 1.5 a 3 metros de altura y un cáliz rojo intenso").

Un botón o enlace con el texto "Explorar" que dirija a la URL correspondiente (ej: /apariencia/).

Configuración especial: Indicar que esta página no herede el título grande de la plantilla page, sino que use el slider como elemento principal.

2. Crear las 4 subpáginas de contenido (apariencia.md, composicion.md, beneficios.md, usos.md):

Para cada una de estas páginas, se debe seguir esta estructura:

Front Matter: Declarar layout: page y el title correspondiente (ej: title: "Apariencia").

Contenido (volcado del archivo .txt):

apariencia.md: Debe contener el texto sobre "Porte y tamaño", "Tallo", "Hojas", y la descripción detallada de "La flor y el cáliz". Dividir estos bloques con subtítulos (##). Añadir una nota visual sugerida: colocar una imagen del cáliz entre el segundo y tercer párrafo (ruta: assets/images/posts/caliz.jpg).

composicion.md: Debe contener el "Rico perfil nutricional" (Calcio, Potasio, Vitamina C) y los "Compuestos bioactivos" (Antocianinas, Flavonoides). Para la parte nutricional, sugerir que los datos se presenten en una lista con viñetas o en una tabla Markdown sencilla de 2 columnas (Nutriente / Cantidad) para hacerla más visual.

beneficios.md: Debe contener los 4 beneficios con respaldo científico. Cada beneficio debe ser un subtítulo (##) seguido de su descripción. Dejar un espacio visual entre cada uno. Añadir un pequeño recuadro o "cita" destacada al final con la frase: "La ciencia respalda lo que la tradición siempre supo."

usos.md: Debe contener los 3 usos (Gastronomía, Medicina tradicional, Industria). Cada uso debe ser un subtítulo (##). Incluir ejemplos concretos como "Agua de Jamaica" o "colorante natural" en negrita dentro del texto para que resalten.

3. Definir la hoja de estilos principal (assets/css/style.scss):

Este archivo es el "alma visual". La IA debe programar las siguientes reglas sin usar código explícito aquí, pero sí definir la lógica de estilos:

Variables globales (Custom Properties): Declarar en :root los 5 colores de la paleta Jamaica (--rojo-profundo: #B71F3E;, --crema: #FDF5F0;, --dorado: #E8A34B;, --verde-hoja: #3D6B4F;, --tinta: #1A1412;).

Tipografía:

Importar las fuentes Playfair Display (para títulos y encabezados) e Inter (para el cuerpo de texto) desde Google Fonts.

Asignar font-family: 'Playfair Display', serif; a todos los h1, h2, h3.

Asignar font-family: 'Inter', sans-serif; a los párrafos, listas y enlaces.

Diseño del Header y menú:

El fondo del header debe ser el blanco roto (#FDF5F0) con una sombra sutil y un borde inferior delgado en rojo profundo.

El menú desplegable (dropdown) en escritorio debe aparecer con un efecto de fundido suave (opacidad y translateY).

En móvil, el menú hamburguesa debe ocupar toda la pantalla o un gran lateral, con un fondo sólido y enlaces con buen padding para el tacto.

Estilo de las tarjetas (Inicio):

Cada tarjeta debe tener fondo blanco, bordes redondeados (border-radius: 12px), sombra suave al pasar el ratón (box-shadow).

El efecto hover debe incluir: la imagen o ícono interno escala ligeramente (1.05x) y aparece una línea decorativa del color rojo profundo debajo del título.

Estilo de las subpáginas (layout page):

El contenedor central debe tener un max-width: 850px y un padding lateral para evitar que el texto toque los bordes en móvil.

Los subtítulos (##) dentro del contenido deben tener una línea decorativa (un border-bottom de 3px en color dorado o rojo) para darle un toque editorial.

Las listas o tablas nutricionales deben tener un fondo ligeramente sombreado y bordes sutiles para que sean fáciles de escanear.

Responsive (Multiplataforma):

Utilizar grid y flexbox para que todo se reordene.

Punto de quiebre (@media max-width: 768px): las tarjetas deben apilarse en una sola columna, el slider debe reducir su altura (por ejemplo, a 40vh en lugar de 60vh), y el menú desplegable debe transformarse en acordeón táctil.

Asegurar que todos los botones y enlaces tengan un área de clic mínima de 44px (estándar de accesibilidad táctil).

4. Preparar la estructura visual del Slider (Carrusel) dentro de index.md:

Dentro de la página de inicio, la IA debe crear un contenedor especial que pueda albergar un carrusel de imágenes con efecto fade (fundido).

El contenedor debe tener 3 diapositivas (slides). Cada diapositiva debe contener una imagen de fondo y un texto centrado.

Las imágenes deben usar object-fit: cover para no distorsionarse.

Los textos de las diapositivas deben tener un efecto de entrada sutil: al cambiar de slide, el texto debe aparecer con un pequeño desplazamiento vertical y una transición de opacidad.

Importante: La IA debe dejar la estructura HTML lista (en el archivo index.md o dentro de un _includes/slider.html que se llame desde index.md), pero la lógica de movimiento automático (el JavaScript) no se programa aquí, se dejará para la Parte 4.

5. Actualizar el archivo de rutas y verificar enlaces:

Revisar que el menú desplegable (creado en la Parte 2) tenga las URLs exactas que coincidan con los nombres de los archivos .md creados en esta parte (/apariencia/, /composicion/, /beneficios/, /usos/).

Verificar que el botón "Explorar" de cada tarjeta en el index.md apunte a su URL correcta.
